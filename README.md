# Calendar

Monthly calendar application built with React and TypeScript.

## Features

* Navigate between months
* Create events by clicking a day
* Display events
* Delete events

## Tech stack

* React
* TypeScript
* Vite
* date-fns
* Vitest
* React Testing Library

## Getting started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Run tests

```bash
npm run test:run
```

### Run linting

```bash
npm run lint
```

### Format the code

```bash
npm run format
```

### Build the application

```bash
npm run build
```
